## STEP 4 — Make the window ACTUALLY transparent (the alpha cut-out)

A `background:transparent` div doesn't cut a hole — the grid is a separate layer
behind it, so transparent just shows the grid. To punch a real hole in the grid,
use a CSS mask on the grid layer so the grid is NOT drawn where the window is.

Replace the grid-bg layer with a masked version:
```html
<div id="grid-bg" style="
  position:absolute; inset:0;
  background-color:#FFFFFF;
  background-image:
    repeating-linear-gradient(0deg,  #E3E3E3 0 1px, transparent 1px 80px),
    repeating-linear-gradient(90deg, #E3E3E3 0 1px, transparent 1px 80px);
  /* Cut a rectangular hole where the speaker window is: */
  -webkit-mask:
    linear-gradient(#000 0 0) padding-box,
    linear-gradient(#000 0 0);
  -webkit-mask-composite: xor;
          mask-composite: exclude;
"></div>
```

Simpler, more reliable method — use clip-path to remove the window region from
the white layer entirely, so V1 shows through cleanly:
```html
<div id="grid-bg" style="
  position:absolute; inset:0;
  background:#FFFFFF;
  background-image:
    repeating-linear-gradient(0deg,  #E3E3E3 0 1px, transparent 1px 80px),
    repeating-linear-gradient(90deg, #E3E3E3 0 1px, transparent 1px 80px);
  clip-path: polygon(
    0 0, 1000px 0, 1000px 140px, 1824px 140px, 1824px 940px,
    1000px 940px, 1000px 1080px, 0 1080px
  );
"></div>
```
The clip-path leaves a rectangular notch (x:1000–1824, y:140–940) where the grid
is not drawn → that region is fully transparent → V1 speaker shows through.
Keep the thin #speaker-window frame (Step 3 Layer 2) for a clean border.

Note: the clip-path coordinates MUST match the window box from Step 3.

## STEP 6 — Render with ALPHA (transparent window must survive)

```bash
# ProRes 4444 carries the alpha channel — required for the transparent window
npx hyperframes render swissgrid-window-[slug] --format mov --transparent
# Save versioned: swissgrid-window-[slug]_v1.mov
```

---

## STEP 7 — Verify the alpha is real

```bash
# Confirm the render actually has an alpha channel:
ffprobe -v error -show_entries stream=pix_fmt -of csv=p=0 swissgrid-window-[slug]_v1.mov
# Should report a format with alpha: yuva444p10le (ProRes 4444) or similar.
# If it says yuv420p (no alpha) → the window will be BLACK, not transparent. Re-render.

python3 verify_render.py
# The extracted frame will show the window area as black (no alpha in PNG) —
# that's expected for a still. The ffprobe pix_fmt check is the real alpha proof.
```
